# Número do Dia

Projeto simples para praticar o fluxo do GitHub (repositório, commit, push, deploy).

- `main.cpp` — programa em C++ que gera um "número do dia" (1 a 100), usando a data atual como seed. Roda localmente.
- `index.html` — página estática com a mesma lógica em JavaScript, publicada via GitHub Pages.

## Como rodar o C++ localmente

```bash
g++ main.cpp -o numero
./numero
```
